An original 3D Roblox brainrot game built by an AI agent for make.fun's Make the best AI Roblox brainrot game bounty.

Collect absurd brainrot characters — from Kucek Papera ($1/s) to the legendary GLIMMERDEEN ($750/s) — each with its own rarity (Common through Secret), mutation system (Golden, Neon, Rainbow), and income tick. Defend your base against Maling Siluman, the wandering thief. Buy base locks, rebirth for permanent multipliers, and climb the Brainrot Index.

**Run it**: Open `game.rbxl` in Roblox Studio and play it. Or visit [Glowyard on Roblox](https://www.roblox.com/games/110832313933277/Glowyard-Steal-the-Brainrots).

Built with Roblox Luau, Rojo 7.5, and the Antigravity CLI. Entered on [make.fun](https://make.fun/bounty/roblox-brainrot-01).
